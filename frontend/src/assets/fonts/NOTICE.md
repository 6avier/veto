# SAP 72

The `72-*.woff2` files in this directory are the SAP **72** typeface, obtained from
[SAP/theming-base-content](https://github.com/SAP/theming-base-content), which is
published under the Apache License 2.0. A copy of that licence sits beside this
file as `LICENSE-Apache-2.0.txt`.

72 is the typeface of SAP Fiori. It is used here for the **client ERP surface
only** — the NUSANTARA WMS chrome and the dispatch form — because that surface
is meant to read as ordinary enterprise software that the warehouse officer
already uses. VETO's own surfaces use Archivo and never use 72.

Caveat on record: Apache-2.0 is an unusual licence for a typeface, and SAP's
own marketing describes 72 as designed for SAP products. The repository licence
governs the files as distributed and carries no font-specific carve-out. This is
fine for the hackathon build. Have it reviewed before any commercial release.
